How it works

One job. Start to settlement.

Every incident runs the same four steps, in order — that's what makes the price predictable.

01

Quote

Send the incident. Encode returns a 402 with a fixed price — $1.50 to triage, $8 for a fix and PR. Nothing runs until you sign.

02

Settle

Your wallet pays over x402 on Celo. One on-chain transaction, straight to Encode — no escrow, no account, no invoice.

03

Diagnose

Encode reads the relevant logs and code, decides whether the incident is real, and works out the likely cause.

04

Fix & verify

A patch is drafted and the tests run — plus the original failure is re-checked against the unpatched code, so "fixed" means something. Then a PR opens. Nothing merges without your review.

For agents & teams

Encode is an x402 endpoint. Any agent can hire it.

Encode doesn't require an account, an API key negotiation, or a support ticket. Send a request; if payment is required, you'll get a 402 back with the price and Encode's wallet. Sign, retry, done.

That means your own monitoring agent, CI pipeline, or another autonomous agent can hire Encode programmatically — no human in the loop on either side.
