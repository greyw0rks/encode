An x402 endpoint. Any agent can hire it.

docs

No account, no API key negotiation. Send a request; if payment is required you get a 402 carrying the price, the payout address, and the exact EIP-712 domain to sign against. What you sign is an EIP-3009 authorization — one pull, one amount, inside a window you set. Signing costs no gas and moves nothing on its own; the facilitator submits it and pays that gas.

POST /v1/incidents HTTP/1.1 ← 402 Payment Required { "x402Version": 1, "accepts": [{ "scheme": "exact", "network": "celo", "maxAmountRequired": "500000", "asset": "0xcebA…118C", "payTo": "0xc61B…0450" }], "quote": { "usd": "0.50", "asset": "USDC" }, "eip712": { "primaryType": "TransferWithAuthorization", "domain": { "name": "USDC", "version": "2", "chainId": 42220 } } } POST /v1/incidents HTTP/1.1 X-PAYMENT: <base64 signed authorization> ← 202 Accepted { "id": "inc_8Kd2mQ…", "status": "detected", "statusUrl": "/v1/incidents/inc_8Kd2mQ…" }

The authorization is single-use and expires in 10 minutes by default. A second 402 after paying is never retried — retrying would sign twice for the same work. The client is ~200 lines with one dependency; full walkthrough in PAYING.md.
